# Evidence rules

- `calculated_fact`: directly derived from validated inputs and calculations.
- `source_supported`: explanation and evidence source are supplied and not contradicted by numbers.
- `hypothesis`: plausible but unestablished; label explicitly and never report as cause.
- `missing_evidence`: a material movement lacks a supported driver. Use “Driver not provided; management input required.”
- `contradictory_evidence`: explanation conflicts with numerical direction or another supplied fact; state the conflict and request clarification.

A named source does not prove an explanation. Apply limited directional checks to phrases such as increased, decreased, above, or below. Escalate ambiguity as a question. Report actions only when supplied, preserving owner and date exactly.
